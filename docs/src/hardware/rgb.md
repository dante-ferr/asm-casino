# Led RGB
O LED RGB possui três entradas: R(ed), G(reen) e B(lue).
## RGB_Set_By_Number
Configura a cor do RGB de acordo com o número sorteado.
## RGB_Set_By_Player
Configura as cores de acordo com o jogador, sendo:
* Jogador 1: Vermelho
* Jogador 2: Azul (para representar o preto)
* Jogador 3: Verde
* Jogador 4: Amarelo
