# Materiais Utilizados

Lista de componentes e materiais para a montagem física do projeto da Roleta Francesa:

## Componentes Principais

- 1x Arduino Uno R3
- 1x Display LCD 16x2 com módulo I2C soldado
- 1x Matriz de LEDs 8x8 MAX7219
- 1x Módulo LED RGB
- 2x Displays de 7 segmentos de 0.56" verde catodo comum
- 1x Buzzer piezoelétrico
- 3x Chaves táteis
- 2x Transistores NPN BC547 ou 2N2222

---

## Resistores e Capacitores

### Resistores
- 10x Resistores de 220 Ohms
- 1x Resistor de 330 Ohms
- 2x Resistores de 1k Ohms
- 2x Resistores de 4.7k Ohms
- 2x Resistores de 10k Ohms
- 1x Resistor de 22k Ohms

### Capacitores
- 1x Capacitor cerâmico de 100nF
- 1x Capacitor eletrolítico de 10µF

---

## Estrutura
- 2x Protoboards de 400 pontos
- Cabos jumper Macho-Macho, Macho-Fêmea e Fêmea-Fêmea
- Caixa de sapato
- Tinta acrílica marrom
